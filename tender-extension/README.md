# Расширение Chrome «КИТ — Тендерный радар»

Расширение собирает подходящие транспортные тендеры с ЕИС, Росэлторга, B2B-Center и Фабриканта, используя текущие авторизованные сессии браузера. Пароли не читаются и не сохраняются.

## Установка

1. Скачайте репозиторий: **Code → Download ZIP**.
2. Распакуйте архив.
3. Откройте в Chrome: `chrome://extensions/`.
4. Включите **Режим разработчика**.
5. Нажмите **Загрузить распакованное расширение**.
6. Выберите папку `kit-leads-main/tender-extension`.
7. Закрепите расширение на панели Chrome.

## Использование

- Войдите на нужные площадки обычным способом.
- Нажмите значок расширения.
- Выберите **Собрать со всех площадок**.
- Откройте тендерный радар — собранные данные появятся автоматически.

Автосбор запускается каждые 30 минут, пока Chrome открыт. CAPTCHA и повторную авторизацию пользователь проходит самостоятельно. Сборщик не обходит защиту площадок.
