# Подключение API к тендерному радару

Сборщик запускается автоматически каждые 30 минут и обновляет `tender-finder/data/tenders.json`.

## Необходимые GitHub Secrets

Откройте: **Settings → Secrets and variables → Actions → New repository secret**.

| Площадка | URL API | Токен |
|---|---|---|
| ЕИС | `EIS_API_URL` | `EIS_API_TOKEN` |
| Росэлторг | `ROSELTORG_API_URL` | `ROSELTORG_API_TOKEN` |
| B2B-Center | `B2B_API_URL` | `B2B_API_TOKEN` |
| Фабрикант | `FABRIKANT_API_URL` | `FABRIKANT_API_TOKEN` |

Токены и пароли нельзя добавлять в файлы репозитория. Если площадка выдаёт отдельный URL метода поиска закупок, укажите его в переменной `*_API_URL`.

## Первый запуск

После добавления переменных откройте **Actions → Обновление тендеров → Run workflow**. В журнале будет видно количество полученных закупок по каждой площадке.

## Важно

Форматы API площадок могут различаться. Текущий коннектор распознаёт распространённые поля: название, заказчик, ИНН, регион, НМЦК, дедлайн и URL. После получения официальной документации конкретной площадки сопоставление полей нужно проверить и при необходимости уточнить.
