# КИТ Leads

Сайт для поиска, проверки и ведения базы потенциальных клиентов транспортной компании КИТ.

Сайт: https://shokhingg-creator.github.io/kit-leads/

Возможности:

- генерация точных запросов для Яндекса, 2ГИС, Google и сервисов проверки контрагентов;
- база компаний с проверкой телефона и контрольной суммы ИНН;
- защита от дублей;
- статусы обработки и оценка потенциала;
- импорт и экспорт CSV для Excel;
- сохранение базы в браузере без передачи данных внешним сервисам.

## Поиск сезонных клиентов по России

[Открыть раздел на GitHub Pages](https://shokhingg-creator.github.io/kit-leads/seasonal-leads/)

Выберите кластер, город поиска и груз — теплицы, системы полива или шины.
Города в выпадающем списке служат подсказками. Можно ввести свой город.
В GitHub Pages доступны переходы в Яндекс и 2ГИС, ручное добавление компаний,
сверка статуса CoWork вручную и выгрузка CSV для Excel.

Для автопоиска используйте Node.js 22+ и ключ [Tavily](https://app.tavily.com/).
Передайте ключ как переменную окружения `TAVILY_API_KEY` или запишите
`TAVILY_API_KEY=...` в локальный файл `seasonal-leads/.env`. Файл исключён из Git.

```sh
node --env-file-if-exists=seasonal-leads/.env seasonal-leads/server.mjs
```

Откройте http://127.0.0.1:8787/. На каждый поиск сервис отправляет два запроса
в Tavily. Из текста источника берутся признак отгрузок, ИНН и корпоративный
email при наличии. Для включения в подборку нужен признак присутствия
в выбранном городе, например адрес склада или производства. Высокий приоритет присваивается при явном упоминании
отправки через транспортную компанию. Город поиска — параметр запроса:
город склада, направление и частоту отгрузок подтверждает менеджер.

Реестр хранится в браузере и привязан к адресу страницы. Записи локального
сервера и GitHub Pages хранятся отдельно. Для общей работы используйте CSV.
```sh
node --test seasonal-leads/search.test.mjs
```
