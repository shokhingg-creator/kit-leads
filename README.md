# КИТ Leads

Сайт для поиска, проверки и ведения базы потенциальных клиентов транспортной компании КИТ.

Сайт: https://shokhingg-creator.github.io/kit-leads/

Возможности:

- генерация точных запросов для Яндекса, 2ГИС, Google и сервисов проверки контрагентов;
- база компаний с проверкой телефона и контрольной суммы ИНН;
- защита от дублей;
- статусы обработки и оценка потенциала;
- импорт и экспорт CSV для Excel;
- сохранение базы в браузере без передачи данных внешним сервисам.
